This page is for Cosmos SDK developers who are new to EVM transactions. When a route starts on an EVM chain (for example Ethereum, Arbitrum, or Optimism), the Skip Go API returns an `EvmTx` object for the user to sign. This page describes its fields and shows how to sign and execute it with `@skip-go/client`.

An EVM transaction has no messages. So an `EvmTx` is not the same as a Cosmos message: it is a single contract call or transfer.

## `EvmTx` Fields

| Field | Description |
|---|---|
| `chain_id` | The EVM chain ID, as a numeric string (for example `"1"` for Ethereum). |
| `to` | The address of the contract or externally owned account (EOA) that the transaction calls, as a `0x`-prefixed hex string. |
| `value` | The amount of native token, in wei, that the transaction sends (1 ETH = 10^18 wei). |
| `data` | The calldata for the contract call, as a hex string. The contract decodes it with its application binary interface (ABI). If it is empty, the transaction only sends funds to `to`. |
| `required_erc20_approvals` | The ERC-20 approvals the user must grant before this transaction can run. See [ERC-20 Approvals](#erc-20-approvals). |
| `signer_address` | The address that must sign the transaction, which is the user's address on this chain. |

For more on EVM transactions, see the [Ethereum documentation](https://ethereum.org/en/developers/docs/transactions/).

### ERC-20 Approvals

To move a user's ERC-20 tokens, a contract needs an allowance from the user. Skip Go returns `required_erc20_approvals` whenever the route needs one. Each entry has these fields:

| Field | Description |
|---|---|
| `token_contract` | The address of the ERC-20 token to approve. |
| `spender` | The address of the contract that receives the allowance. |
| `amount` | The amount of `token_contract` tokens the `spender` may spend. |

If the user's current allowance is lower than `amount`, an approve transaction must be signed and submitted before the `EvmTx`. Otherwise the `EvmTx` fails with a permission error.

* With `@skip-go/client`, `executeRoute` checks the allowance and asks the user to approve when needed.
* With the REST API, check the allowance and send the approve transaction yourself.

For more on approvals, see [EIP-20](https://eips.ethereum.org/EIPS/eip-20).

## Execute an EVM Route with `@skip-go/client`

The example below moves USDC from Ethereum to Arbitrum. It uses [viem](https://viem.sh/) as the EVM library. [ethers.js](https://docs.ethers.org/) and [web3.js](https://docs.web3js.org/) also work.

### 1. Install the libraries

```shell
npm i viem @skip-go/client
```

### 2. Create an EVM signer

`executeRoute` asks for a signer for each EVM chain it needs to sign on. Provide a `getEvmSigner` function that returns a viem `WalletClient` for a chain ID. The `WalletClient` queries the chain for data such as the nonce and gas price, and signs and broadcasts transactions.

```typescript
import { createWalletClient, custom, type Chain } from 'viem';
import * as chains from 'viem/chains';

const getEvmSigner = async (chainId: string) => {
  const chain: Chain | undefined = Object.values(chains).find((c) => c.id === Number(chainId));
  return createWalletClient({ chain, transport: custom(window.ethereum!) });
};
```

### 3. Request a route

```typescript
import { route } from '@skip-go/client';

const skipRoute = await route({
  amountIn: '1000000',
  sourceAssetDenom: '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48',
  sourceAssetChainId: '1',
  destAssetDenom: '0xaf88d065e77c8cC2239327C5EDb3A432268e5831',
  destAssetChainId: '42161',
  smartSwapOptions: { splitRoutes: true },
});
if (!skipRoute) throw new Error('No route found');
```

### 4. Get a user address for each required chain

`requiredChainAddresses` lists every chain that needs a user address: the source chain, the destination chain, and any intermediate chain that needs a recovery address in case of a failure.

```typescript
const userAddresses: { chainId: string; address: string }[] = [];
for (const chainId of skipRoute.requiredChainAddresses) {
  if (!Number.isNaN(Number(chainId))) {
    // EVM chain IDs are numeric
    const signer = await getEvmSigner(chainId);
    const [address] = await signer.requestAddresses();
    userAddresses.push({ chainId, address });
  } else {
    // Cosmos and SVM wallets -- not shown
  }
}
```

### 5. Execute the route

`executeRoute` asks the user to sign any required approvals and the transaction, then submits them.

```typescript
import { executeRoute } from '@skip-go/client';

await executeRoute({ route: skipRoute, userAddresses, getEvmSigner });
```
