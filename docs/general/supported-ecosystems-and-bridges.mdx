<Info>
 **Keep Smart Relay enabled for global coverage of all chains, bridges, and routes**
 
 Smart Relay is enabled by default on `/route` and `/msgs_direct`. Many routes will return a RouteNotFound error if you set `smart_relay=false`, because there are no public relayers that support them. This includes all routes to and from Solana, as well as CCTP routes between EVM chains such as Arbitrum and Base.
 
 As a result, if you want your users to be able to transfer their tokens over all routes, do not turn off [Smart Relay](/general/smart-relay).
</Info>

Skip Go API is a universal interoperability platform. It can be used to swap and transfer tokens within and between all major ecosystems in crypto over many major bridges. We're constantly adding new bridges, new chains, new routes on already-supported bridges, and new multi-hop routes by composing multiple bridges together. 

This document gives a high level overview of the different ecosystems and bridges Skip Go API supports, including how to onboard assets into each ecosystem, when different bridges are used, and what DEXes are supported. 

For each major ecosystem, this document identifies: 

* The bridges over which Skip Go API can route users into and out of the ecosystem
* The bridges over which Skip Go API can route users within the ecosystem
* The DEXes where Skip Go API can swap within the ecosystem

The very short summary is that our Cosmos ecosystem support is most mature, followed by Ethereum, followed by Solana. 

<Note>
Eureka, Stargate, and LayerZero routes are opt-in. To include them, add `"eureka"`, `"stargate"`, and/or `"layer_zero"` to the `experimental_features` array in your `/route` and `/msgs_direct` requests (or the `experimentalFeatures` option in the Widget and Client Library).
</Note>

## Cosmos Support Details

**Onboard and offboard via**: 

* Axelar (Move major tokens to Ethereum, Polygon, Avalanche, and ETH L2s)
* CCTP via Noble (Move USDC to all major Ethereum L2s, Polygon, Avalanche, and Solana)
  - Maximum transfer limit: 500,000 USDC per transfer
* CCTP V2 via Injective (Move USDC between Injective EVM and Ethereum, its major L2s, Polygon, Avalanche, and Solana. Transfers to and from other Cosmos chains are forwarded over IBC through Injective)
  - Maximum transfer limit: 10,000,000 USDC per transfer
* Go Fast (Move assets at faster-than-finality speeds from EVM to Cosmos)
  - Currently, Go Fast supports the following source chains: Ethereum Mainnet, Arbitrum, Avalanche, Base, Optimism, Polygon.
* Eureka (IBC v2 that enables seamless interoperability between Cosmos and Ethereum ecosystem)
* LayerZero (Move supported OFT tokens between Initia and EVM chains)

**Move within the ecosystem via:** 

* IBC
* OPinit (Move assets between Initia and its rollups)

**Swap within the ecosystem on:**

* Osmosis
* Astroport (on Injective, Sei, and Terra)
* InitiaDEX
* White Whale (on Chihuahua, Injective, Sei, and Terra)
* Dojoswap (on Injective)
* Helix (on Injective)
* Tower (on Babylon)
* Dexter (on Persistence)
* Nauticus, Phoenix, Terraswap, and Ura (on Terra)

## Ethereum Support Details
 <Warning>
 **Never attempt to derive Cosmos Addresses from Ethereum Addresses (or vice versa)**
 
 Whenever you need an address on a chain for a user, please request it from the corresponding wallet. 
 
 If you attempt to derive an address on one chain from an address on another chain, you may derive an address that the user cannot actually sign for if the two chains have different address-derivation processes. For example, if you derive a Cosmos address from an Ethereum address, you will get an address that the user cannot sign for or use. 
 
 So don't ever try to derive one address from another -- even for intermediate addresses. (Intermediate addresses may be used for fund recovery if there is some kind of failure on an intermediate chain. Failures could include a timeout, a swap exceeding slippage tolerance, or any other unexpected execution path. We assume users can sign for intermediate addresses, even if they shouldn't have to.)
</Warning>

**Onboard and offboard via:** 

* CCTP (Move USDC to/from Cosmos via Noble)
  - Maximum transfer limit: 500,000 USDC per transfer
* CCTP V2 (Move USDC to/from Solana)
  - Maximum transfer limit: 10,000,000 USDC per transfer
* Axelar (Move ETH and other major tokens to/from Cosmos)
* Go Fast (Move assets at faster-than-finality speeds)
* Eureka (Seamless interoperability between Cosmos and Ethereum ecosystem)
* LayerZero (Move supported OFT tokens to/from Initia)

**Move within ecosystem via:** 

* Axelar (Move major assets among all major ETH L2s, Polygon, and Avalanche)
* CCTP V2 (Move USDC among Ethereum, Arbitrum, Avalanche, Base, Injective EVM, Optimism, and Polygon)
  - Maximum transfer limit: 10,000,000 USDC per transfer
* Stargate (Move supported assets among Ethereum, Arbitrum, Avalanche, Base, Binance, Linea, Optimism, Polygon, and Sei)
* LayerZero (Move supported OFT tokens among Ethereum, Arbitrum, Avalanche, Base, Binance, Linea, Optimism, Polygon, and Sei)

**Skip Go API supports swapping on DEXes within the Ethereum ecosystem**

* Uniswap V2/v3 (on Arbitrum, Avalanche, Base, Binance, Blast, Celo, Ethereum, Optimism, and Polygon)
* Velodrome (Optimism)
* Aerodrome (Base)

## Solana Support Details

**Onboard and offboard via:**

* CCTP V2 (Move USDC to/from Ethereum/L2s and Injective EVM)
  - Maximum transfer limit: 10,000,000 USDC per transfer
* CCTP (Move USDC to/from Cosmos via Noble)
  - Maximum transfer limit: 500,000 USDC per transfer

**Move within ecosystem via:** 

* NA -- Solana is just 1 chain

**Skip Go API does not support swapping on any DEXes within the Solana ecosystem at this time**
