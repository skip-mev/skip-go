<AccordionGroup>
  <Accordion title='How do I fix the "Buffer is not defined" error?'>
    The widget depends on Node.js modules that aren't available in the browser. Add polyfills for those modules with the plugin for your build tool:

    - [Webpack](https://www.npmjs.com/package/node-polyfill-webpack-plugin)
    - [Rollup](https://www.npmjs.com/package/rollup-plugin-polyfill-node)
    - [Vite](https://www.npmjs.com/package/vite-plugin-node-polyfills)
    - [ESBuild](https://www.npmjs.com/package/esbuild-plugins-node-modules-polyfill)
  </Accordion>

  <Accordion title="Should I put the widget inside a container with a fixed size?">
    Yes. The widget uses shadow DOM, which renders on the client, so a fixed-size container prevents layout shift while it loads. We recommend a height of `640px` and a width of `500px`.
  </Accordion>

  <Accordion title="Can I use Safe multisig wallets with the widget?">
    Yes. [Safe](https://app.safe.global) wallets work through wallet providers that support Safe:

    - **Rabby Wallet**: Import and use a Safe wallet.
    - **WalletConnect**: Connect a Safe wallet over the WalletConnect protocol.

    <Warning>
    Before a cross-chain transfer, make sure the Safe wallet is deployed on every destination chain. Safe addresses are deterministic, but the wallet contract must exist on each chain where you receive funds.
    </Warning>
  </Accordion>

  <Accordion title="Why am I getting a CORS error?">
    Your domain needs to be whitelisted to use the widget's default Skip Go API endpoint. To get whitelisted, open a support ticket in our [Discord server](https://discord.gg/interchain).
  </Accordion>
</AccordionGroup>
