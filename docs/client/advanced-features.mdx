## Adding custom Cosmos messages to route execution

`executeRoute` accepts an `appendCosmosMsgs` option for custom Cosmos messages, keyed by chain ID (`Record<chainId, CosmosMsg[]>`). Despite its name, it inserts these messages **before** the existing messages in the first Cosmos transaction for each chain ID. So the custom messages run before the route's messages in that transaction and can't depend on their output.

```typescript
import { executeRoute } from '@skip-go/client';

const msg = JSON.stringify({
  fromAddress: 'cosmos1...',  // sender address
  toAddress: 'cosmos1...',    // recipient address
  amount: [{
    denom: 'uatom',
    amount: '1000000'         // amount in the smallest unit (here, micro-ATOM)
  }]
});

await executeRoute({
  route,
  userAddresses,
  appendCosmosMsgs: {
    'cosmoshub-4': [{ msgTypeUrl: '/cosmos.bank.v1beta1.MsgSend', msg }]
  },
  // ...signers and other options
});
```

## Use the Go Fast Transfer system

To use [Go Fast](/advanced-transfer/go-fast), pass `goFast: true` to `route`, then pass the returned route to `executeRoute`.

```typescript
import { executeRoute, route } from '@skip-go/client';

const skipRoute = await route({
  goFast: true,
  // ...other route parameters
});
if (!skipRoute) throw new Error("No route found");

await executeRoute({
  route: skipRoute,
  userAddresses,
  // ...signers and other options
});
```

## Add a fee payer to Solana transactions

`executeRoute` accepts an `svmFeePayer` option so that a different account pays the Solana transaction fees.

```typescript
import { Keypair } from "@solana/web3.js";
import nacl from "tweetnacl";
import bs58 from "bs58";
import { executeRoute, route } from '@skip-go/client';

const skipRoute = await route({
  // ...route parameters
});
if (!skipRoute) throw new Error("No route found");

await executeRoute({
  route: skipRoute,
  userAddresses,
  svmFeePayer: {
    address: 'FEE_PAYER_ADDRESS', // the fee payer's Solana address
    signTransaction: async (dataToSign: Buffer) => {
      // Example only: signs with a private key held in code
      const keypair = Keypair.fromSecretKey(bs58.decode("FEE_PAYER_PRIVATE_KEY"));
      return nacl.sign.detached(dataToSign, keypair.secretKey);
    },
  },
  // ...signers and other options
});
```

<Warning>
Don't put a real private key in frontend code. In production, sign on a server you control.
</Warning>
